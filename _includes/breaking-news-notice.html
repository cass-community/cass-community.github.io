{% comment %} breaking-news-notice.html Displays recent news items in a notice box. If there are no news items that fit the parameters, nothing is displayed. News posts may include frontmatter entries to control whether the post appears in the notice box. expires: The date after which the post should not appear in the notice box. last_modified_at: The date to which the `look_back` parameter is compared. If the key is not present, Jekyll extracts a date from the filename of the post which is used instead. The `expires` key takes precedence over the `last_modified_at` key in deciding to display a post in the notice box. Note that these dates affect only the display in the notice box, not the display in the News collection itself. Parameters look_back: the number of days in the past items are still considered "recent" (default: 30) {% endcomment %} {% assign news_collection = include.collection | default: 'news' %} {% assign news_sort_by = include.sort_by | default: 'date' %} {% assign news_sort_order = include.sort_order | default: 'reverse' %} {% assign news_layout = include.entries_layout | default: 'list' %} {% assign news_class = include.class | default: 'notice notice--info' %} {% assign news_look_back = include.look_back | default: 30 %} {% capture news_icon %}{% include icon-map-lookup label="News" %}{% endcapture %} {% comment %} Convert look_back into a date we can compare to {% endcomment %} {% assign now = site.time | date: "%s" | plus: 0 %} {% assign seconds_back = news_look_back | times: 86400 %} {% assign back_date = site.time | date: "%s" | minus: seconds_back | plus: 0 %} {% comment %} Filter the collection down to the "recent" entries: anything in the future, and anything in the past up to `news_look_back` days ago. Unfortunately, filtering the collection array using where_exp doesn't work when we're comparing dates. So we need to manually create the filtered array. If the post has an `expires` date, we use that to decide whether to include it. Otherwise, we compare the newer of the `date` or `last_modified_at` date with the `look_back` date and include it if it is within the look_back period. The `date` value is what Jekyll extracts from the filename. {% endcomment %} {% assign breaking_news = "" | split: "," %} {% for i in site[news_collection] %} {% if i.expires %} {% assign iexpires = i.expires | date: "%s" | plus: 0 %} {% if iexpires > now %} {% assign breaking_news = breaking_news | push: i %} {% endif %} {% else %} {% assign idate = i.date | date: "%s" | plus: 0 %} {% assign ilma = i.last_modified_at | date: "%s" | plus: 0 %} {% if ilma > idate %} {% assign idate = ilma %} {% endif %} {% if idate >= back_date %} {% assign breaking_news = breaking_news | push: i %} {% endif %} {% endif %} {% endfor %} {% comment %} Display iff there is actually news within our window {% endcomment %} {% if breaking_news.size != 0 %}
